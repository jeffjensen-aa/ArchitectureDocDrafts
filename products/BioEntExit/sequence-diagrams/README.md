# BioEntExit — Sequence Diagrams

This directory contains sequence diagrams that describe the temporal interactions between components, actors, and services within the BioEntExit system.

## Diagrams

| Diagram | Description |
|---------|-------------|
| [User Entry Flow](./user-entry-flow.md) | A registered user authenticates at an entry checkpoint and gains access |
| [User Exit Flow](./user-exit-flow.md) | A registered user's departure is detected and logged |
| [User Enrollment Flow](./user-enrollment-flow.md) | An administrator enrolls a new user's biometric data and access rights |
| [Failed Authentication Flow](./failed-authentication-flow.md) | Handling of a failed biometric match at a checkpoint |
